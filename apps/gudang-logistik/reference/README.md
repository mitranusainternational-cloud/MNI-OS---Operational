# Source reference

`MNI OS - Gudang & Logistik.html` adalah salinan sumber HTML asli yang dipertahankan apa adanya untuk pembandingan. Pengembangan aktif dilakukan pada `../index.html`, `../assets/css/app.css`, dan `../assets/js/app.js`. Tinjau perbedaan dan asal data sebelum mengganti atau menggabungkan implementasi.

Catatan 2026-11-02: salinan ini hanya memakai 15 dari 20 koleksi schema mni-app dan **bukan** sumber build. Sumber kebenaran UI adalah `../index.html` dan `../assets/` (lihat [[documentation/DECISIONS]]).
