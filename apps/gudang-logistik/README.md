# Aplikasi Gudang & Logistik MNI

Aplikasi aktif dan catatan teknisnya berada di folder ini. Mulai dari `index.html`; detail ada di `docs/`. Salinan HTML sumber yang dipertahankan untuk pembandingan berada di `reference/`.

Aplikasi membutuhkan runtime `window.claude` untuk database, identitas pengguna, sinkronisasi, dan unduhan.
