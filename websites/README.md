# Website

Simpan setiap website pada subfolder sendiri. Aplikasi utama gudang/logistik saat ini berada di `apps/gudang-logistik/`; situs lain dan situs dokumentasi disimpan di `websites/`. Sertakan README yang menjelaskan tujuan situs, teknologi, cara preview lokal, sumber konten/aset, serta cara publikasi.

Peta roadmap website ada di [[documentation/ROADMAP|roadmap workspace]]. Status progres yang lintas aplikasi dicatat di [[documentation/PROJECT_PROGRESS|progress proyek]].

Jangan menaruh secret deployment di folder ini. Simpan konfigurasi publik dan contoh environment dengan nilai dummy saja.
