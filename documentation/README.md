# Dokumentasi

Simpan SOP, standar kerja, peta proses, panduan peran, dan keputusan operasional di sini. Gunakan subfolder per proses jika koleksi berkembang.

Saat mencatat perubahan proses, isi minimal: tujuan, pemilik proses, pemicu, langkah, bukti/rekaman, dan tanggal berlaku. Tautkan hasil riset terkait.
