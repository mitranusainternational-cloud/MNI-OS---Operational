# Data kerja lokal

Workbook sumber Operasional disimpan di `private-sources/` pada mesin kerja ini. Folder tersebut dikecualikan dari Git karena file berisi data bisnis. File asli dari Temp/Downloads dipertahankan; salinan di sini hanya untuk memusatkan akses kerja lokal.

Gunakan [[documentation/DATA_SOURCE_CATALOG|katalog sumber data]] untuk inventaris, pemilik, periode, definisi, dan status validasinya. Jangan mengirim folder privat ini ke GitHub, Vercel, atau dokumentasi publik. Jangan mengedit sumber mentah; lakukan pembersihan pada salinan analisis yang terpisah setelah aturan disepakati.
